# 岩井俊二风格·AI情感短剧·Skill

## 层1:宏观原则(战略层)

| 原则 | 说明 |
|---|---|
| 核心定位 | 50秒以内·1-2句旁白·复刻经典电影桥段·击中"未说出口"+"失去后才懂"+"日常器物承载情感"三大底层共鸣点 |
| 目标平台 | 视频号/抖音/小红书 (35-55岁主力 + 18-25岁高考群体双重覆盖) |
| 适用边界 | 只管"岩井俊二克制情感"路线——慢动作+静默+日常细节+未说出口+逆光过曝+留白 |

## 层2:通用规则(战术层)

### 适用边界判别(写剧本前必答三问)

| 问题 | 判定 |
|---|---|
| 核心是"情感克制"还是"视觉冲击"? | 视觉冲击=不调用 |
| 时长是 50秒 还是 10-15秒? | 短时长=不调用本 skill 的 50秒结构 |
| 是否有"未说出口"+"失去后才懂"+"日常器物"至少 2 个共鸣点? | 否则不调用 |

### 不复用本 skill 的任务类型

| 任务类型 | 为什么不复用 | 怎么做 |
|---|---|---|
| 游戏化/转场风格(学士服→西装+血槽UI+地图解锁) | 核心是视觉冲击+系统化隐喻,不是情感克制 | 走通用剧本工作流:先列"1:1 保留项",再升级运镜/光影/UI 设计 |
| 动作/特效向(爆炸/打斗/科幻) | 岩井模板全是慢镜头+静默,反向 | 走剧本基本结构(场景/动作/对白/镜头),不调用本 skill |
| 写实电影质感+短时长(10-12秒) | 岩井模板默认 50秒+5个变体填空;10秒短剧需紧凑运镜+色温变化+具体 dolly 参数 | 参考"运镜参数化"+音效具体到歌名 |
| 多镜头剪接/快切 | 岩井模板偏好"长镜头+不切" | 走普通分镜表,每秒1-2镜 |

### 已知坑(禁止行为)

| 坑 | 后果 | 修复 |
|---|---|---|
| ❌ M3写剧本 | 20K顺从流水账,会被打回 | 必须用高阶模型 thinking max(铁律) |
| ❌ 旁白超过30字 | 煽情,失分 | 强制 ≤30字 |
| ❌ 标题写"青春不散场"/"毕业季"等烂俗词 | 直接报废 | 重写 |
| ❌ 不用"逆着人流往回走"这类回望动作 | 缺视觉钩子,完播率掉 | 必加回望动作 |
| ❌ BGM写"抒情钢琴"/"温暖音乐" | 不具体 | 必须给1首歌名 |

## 层3:操作流程(执行层)

### 工作流

```
① 确认题材/情感击中点(1-2个关键词,如"高考+未说出口")
  ↓
② 套选题公式生成 5个变体(1句话1个)
  ↓
③ 选 1个最强变体展开 50秒剧本(高阶模型 thinking max,强制用PRO)
  ↓
④ 按模板输出:标题+分镜+旁白+BGM+共鸣点+复刻来源
  ↓
⑤ 写完交付,不展开额外内容(1件事1条消息铁律)
```

### 选题公式(可复制)

```
"______" 是 "______" 最后的 ______
```

**填空规则**:
- 空1 = 一个日常校园物件/痕迹(值日表/借书卡/课桌/毕业照/校服/同学录/铅笔字)
- 空2 = 一段从未说出口的关系/情感(三年暗恋/那句喜欢/两个人的名字)
- 空3 = 该物件扮演的角色(证据/墓碑/证人/伪装/回音/并排)
- 必有动作 = "逆着人流往回走"式的回望时刻

**击中的人性底层情感**(3个关键词):遗憾 / 后知后觉 / 来不及

### 剧本模板(50秒·严格执行)

```markdown
# 标题: (8-15字, 钩子)

## 50秒剧本
[00-05s] 画面: ...
[05-10s] 画面: ...
(精确到秒, 50秒以内, 共8-10个分镜)

## 旁白 (1-2句, 不超过30字)
"..."

## BGM建议
(具体到1首歌, 不要"抒情钢琴"这种空话)

## 共鸣点分析 (3条, 每条1句话)
1. ...
2. ...
3. ...

## 复刻来源
(致敬哪部岩井俊二作品+具体桥段)
```

### 硬约束

- 标题不烂俗("青春不散场"/"毕业季"这种不要)
- 旁白克制,1-2句点到即止
- 画面可执行(AI视频生成工具能拍出来的)
- 不出现"梦想"/"加油"/"未来可期"口号
- 击中"失去后才懂"+"未说出口"+"日常细节"至少2个
- 共鸣点不是"煽情",是"真实生活场景"

## 层4:数据来源(验证层)

### 5个已验证变体(高考/毕业季直接套)

1. **借书卡并排**: "借书卡上的借阅记录"是"两个人的名字"最后的并排——毕业前最后一次还书,才发现所有记录紧挨着
2. **课桌告白**: "课桌角被磨平的刻痕"是"三年同桌"最后的告白——清空教室时逆光才看清那行铅笔字
3. **毕业照视线**: "毕业照里永远隔着的三排人"是"一直在看你"最后的证据——洗出来才发现有人没看镜头
4. **同学录伪装**: "同学录上只写了前程似锦的那页"是"我喜欢你"最后的伪装——铅笔痕在光下透出擦掉的四个字
5. **车站证人**: "校门口等了三年没一起走的车站"是"暗恋"最后的证人——毕业那天独自逆着人群走回去

### 岩井俊二风格必备元素(命中越多越像)

- 逆光/过曝/留白
- 慢动作+静默
- 日常细节放大(书本/单车/教室走廊/夕阳/橡皮/粉笔字)
- 主观镜头+特写
- 结尾的"失去后才懂"
- "逆着人流往回走"类回望动作
