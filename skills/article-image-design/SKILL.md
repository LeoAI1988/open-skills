# 文章配图设计

## 先锁定文字

文字尚未定稿时先完成文字确认。用户确认后，固定标题、副标题、正文摘录和图片数量；未经允许不改字。

## 确认规格

| 场景 | 常用比例 |
|---|---|
| 公众号正文 | 5:3 横版 |
| 图文平台封面 | 3:4 竖版 |
| 短视频封面 | 9:16 竖版 |
| 通用社交卡片 | 1:1 方形 |

以平台实时要求和用户指定为准，不把默认比例当成硬规则。

## 设计系统

每组图片先定义：

- 主色、辅助色和背景色；
- 标题、正文和注释字号层级；
- 网格、边距、圆角与留白；
- 插图、照片、终端、杂志或信息图风格；
- 系列图的统一编号和页脚规则。

公开图片默认不放真实姓名、头像、联系方式、二维码、账号或地理信息；用户明确授权时也只加入必要内容。

## 工具选择

- 需要人物、场景或插画：使用可用的图像生成工具；
- 需要中文准确、版式固定：优先 HTML/CSS 或设计工具；
- 需要在现有图片上修改：使用图像编辑能力并保留原图备份。

不要在 Skill 中写死模型、密钥、账号、私有接口或本地路径。

## 生成提示词模板

```text
用途：[平台与位置]
比例：[宽高比]
主题：[核心概念]
画面：[主体、环境、构图、镜头、光线]
风格：[视觉语言]
文字：[精确标题；无法可靠渲染时留空后排版]
颜色：[主色与背景]
限制：[不要出现的元素]
```

## 系列卡片流程

1. 把文章拆成封面、核心观点、案例、结论和行动页。
2. 每张只表达一个重点。
3. 先做一张样式页，通过后再批量生成。
4. 检查标题截断、中文错字、对齐、对比度和移动端可读性。
5. 一次性交付同一版本，避免混入过期图片。

## 交付检查

- 尺寸、比例、数量和格式正确；
- 文字与定稿逐字一致；
- 版权或授权来源清楚；
- 不含个人信息、隐藏元数据或敏感标识；
- 系列视觉一致，文件命名可追踪。
