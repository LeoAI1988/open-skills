# 文章配图设计

## 用途

为公众号、图文平台和短视频内容生成封面、正文配图与系列卡片。默认可采用黑底荧光绿终端风，也可以根据文章主题建立新的视觉系统。

## 工具选择

| 优先级 | 工具 | 适用场景 | 注意事项 |
|---|---|---|---|
| 1 | GPT Image | 人物、场景、插画和完整视觉创意 | 中文文字需逐字检查 |
| 2 | Nano Banana | 备选图像生成与图片编辑 | 复杂中文排版可能不稳定 |
| 3 | HTML/CSS | 需要中文准确、版式固定、系列统一 | 视觉素材感较弱但可精确控制 |

具体工具以当前可用能力和用户指定为准。不得把真实 API 密钥、账号、私有接口或本地路径写进 Skill 或交付文件。

## 常用比例

| 比例 | 常见场景 | 参考尺寸 |
|---|---|---|
| 5:3 横版 | 公众号正文配图 | 1200×720 |
| 3:4 竖版 | 小红书或公众号封面 | 1080×1440 |
| 9:16 竖版 | 视频号、抖音封面 | 1080×1920 |
| 1:1 方形 | 通用社交卡片 | 1080×1080 |

默认先采用平台最常见比例；用户明确指定尺寸或平台有新要求时，以用户和平台当前规范为准。

## 设计系统

每组图片先确定：

- 主色、辅助色、背景色和高亮色；
- 主标题、副标题、正文、注释的字号层级；
- 网格、边距、留白、圆角和页脚规则；
- 照片、插画、终端、杂志或信息图等视觉方向；
- 系列图的编号、标题位置和品牌签名格式。

### 终端风参考

```css
--bg: #000000;
--green: #00F58A;
--white: #FFFFFF;
--gray: #666666;
```

### 字体层级参考

- 封面主标题：160px 以上；
- 内页标题：80–120px；
- 副标题：40–60px；
- 正文：24–32px；
- 页脚或签名：20px 左右。

实际字号需要结合画布、文字长度和移动端预览调整。

## 品牌签名

需要署名时使用占位模板：

```text
⌘ [作者名] · [AI 助手名]
```

只在用户明确提供并授权时填入真实名称或品牌。公开图片默认不加入私人姓名、头像、联系方式、二维码、账号或地理信息。

## 工作流

### 1. 确认规格

确认用途、平台、比例、文字、数量和期望风格。

### 2. 锁定文字

文字必须先定稿，再开始批量作图。用户确认后，固定标题、副标题和正文摘录；未经允许不改字。

### 3. 选择工具

- 需要人物、场景或插画：优先图像生成；
- 需要中文百分之百准确：优先 HTML/CSS 或设计工具；
- 修改现有图片：使用图片编辑能力并保留原图；
- 系列卡片：先做一张样式页，通过后再批量。

### 4. 生成与排版

提示词模板：

```text
用途：[平台与位置]
比例：[宽高比]
主题：[核心概念]
画面：[主体、环境、构图、镜头、光线]
风格：[视觉语言]
文字：[精确标题；无法可靠渲染时留空后排版]
颜色：[主色与背景]
限制：[不要出现的元素]
```

终端风示例：

```text
Black background, neon green (#00F58A) terminal aesthetic.
Main title: "[标题]" in white, bold and highly legible.
Subtitle: "[副标题]" in neon green.
Brand signature: "⌘ [作者名] · [AI 助手名]" in small gray type.
Layout: [5:3 landscape / 3:4 portrait].
Style: minimalist, high contrast, technology editorial design.
```

### 5. 交付

先检查，再统一交付同一版本。用户不满意时，根据具体问题修改提示词或排版，不混入过期图片。

## HTML/CSS 备选

当图像生成出现中文乱码、错字或对齐错误时，使用 HTML/CSS 精确排版：

```html
<div class="container">
  <div class="title">[标题]</div>
  <div class="subtitle">[副标题]</div>
  <div class="signature">⌘ [作者名] · [AI 助手名]</div>
</div>
```

```css
.container { width: 1200px; height: 720px; position: relative; background: #000; }
.title { color: #fff; font-size: 160px; font-weight: 900; }
.subtitle { color: #00f58a; font-size: 60px; }
.signature { position: absolute; right: 30px; bottom: 30px; color: #666; font-size: 20px; }
```

用浏览器或渲染工具生成最终图片，并检查字体加载和裁切。

## 系列卡片

1. 把文章拆为封面、核心观点、案例、结论和行动页。
2. 每张只表达一个重点。
3. 先完成一张样式页并确认。
4. 批量生成后检查标题截断、错字、对齐和移动端可读性。
5. 一次性交付同一版本。

## 交付检查

- [ ] 尺寸、比例、数量和格式正确。
- [ ] 文字与定稿逐字一致。
- [ ] 中文没有乱码、错字或截断。
- [ ] 系列图的色彩、网格和页脚一致。
- [ ] 图片、字体和素材具有合法使用条件。
- [ ] 不含用户或家人的私人身份、联系方式、账号与隐藏元数据。
