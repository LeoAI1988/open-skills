# 中文内容创作 Skill

一个技能覆盖全部中文内容生产场景。

## 一、原创长文

**触发：** "帮我写一篇关于 X 的长文""写一篇深度内容""3000 字原创"

### 核心方法

不是"写一篇关于 X 的文章"，而是找到**只有这个角度才能这样写的理由**，然后用专业结构呈现。

### 流程

**Step 1：受众分析**
- 谁在读？焦虑什么？
- 已知什么？什么让他们愿意花 10 分钟读完？

**Step 2：差异化角度策划**
- 避开"大家都这么说"的角度
- 找反直觉/反经验的切入点
  - 例：「换掉主力模型，不是因为它差，而是因为它什么都还行」
- 输出策划方案（标题候选+结构+角度），**等用户确认再写**

**Step 3：张力弧线结构**
- 钩子开场（前 2-3 段必须抓人）
- 矛盾呈现（"你不觉得奇怪吗…"）
- 分析拆解（为什么是这样的）
- 解决方案（所以你应该…）
- 行动号召

**Step 4：强钩子写作**
- 不要"随着 X 的到来""在当今社会"
- 用具体场景开场，不用抽象概括
- 每 300 字换一个小节奏

### 字数标准

| 类型 | 字数 |
|------|------|
| 短篇 | 1000-2000 |
| 中篇 | 2000-4000 |
| 长文 | 3000-8000 |

## 二、爆款改写

**触发：** "改成我的风格""参考这篇爆款帮我也写一篇"

### 核心原则

洗稿不是同义词替换，而是**理解参考内容为什么有效，然后用自己的语言和素材重新表达同样的有效性**。

### 五步工作流

1. **拆解有效结构** — 原文为什么有效：钩子、情绪节奏、案例逻辑
2. **保留核心逻辑** — 论证链条保留
3. **替换全部表达** — 比喻换成自己的、案例换成自己的
4. **替换全部素材** — 数据、引用、故事全部重找
5. **验证原创性** — 任意 15 字连续片段与原文不重合

### 质量门槛

- ✅ 结构可学
- ✅ 逻辑可用
- ✅ 表达、案例、比喻全部新写

## 三、去 AI 味润色

**触发：** "去掉 AI 味""读起来太 AI 了"

### AI 写作的 8 大病症

| 病症 | 特征 | 修改方法 |
|------|------|---------|
| 过度过渡句 | "值得注意的是""不可否认的是" | 直接删除或换成"但""不过" |
| 并列堆砌 | 一连串"A、B 和 C" | 挑最重要的一个，其他砍掉或用句号分开 |
| 空洞概括 | "在当今社会""随着时代的发展" | 替换为具体场景或直接删除 |
| 设问开头 | "你有没有想过…""你是否曾…" | 换成直接陈述或故事开头 |
| 机械三段论 | "首先…其次…最后…" | 打散结构，用节奏代替序号 |
| 过度引用 | 每段都引专家/研究 | 最多一条引用，其余用自己的话 |
| -ing 持续态 | "日益增长的技术正在改变…" | 换成过去时或完成时 |
| AI 高频词 | 赋能、深耕、洞察、范式、共鸣 | 替换成大白话 |

### 流程

1. **逐类诊断** — 按上表逐条检查
2. **分类标记** — 哪类病、哪段、怎么改
3. **重写** — 输出对比版
4. **最终检查** — 再读一遍看有没有漏

## 四、人声化处理

**触发：** "让这段话像真人说的""把这段口语化"

### 核心原则

人声化不是简单地加语气词，而是**还原真实说话时的节奏和逻辑**。

### 真人说话的特征

| 特征 | AI 缺失 | 真人做法 |
|------|---------|---------|
| 短句多 | 长句堆砌 | 一句话一个意思 |
| 重复强调 | 怕啰嗦 | "我跟你说啊，我跟你说" |
| 半截转折 | 逻辑太完整 | "其实吧…算了不说了" |
| 口头禅 | 无 | "你知道吗""怎么说呢" |
| 具体细节 | 抽象概括 | "昨天下午三点"而不是"某天" |
| 情绪起伏 | 平铺直叙 | 激动时加快，难过时放慢 |

### 流程

1. **识别场景** — 演讲/对话/独白/口播
2. **匹配节奏** — 按场景调整长短句比例
3. **加入人味** — 口头禅、停顿、重复、半截转折
4. **朗读测试** — 读出来不像 AI 念稿

## 五、商单文案

**触发：** "写个商单""帮写广告""带货文案"

### 核心原则

商单不是硬广，是**让用户看完不反感还愿意下单的内容**。

### 三层结构

**Layer 1：场景共鸣（前 200 字）**
- 不直接说产品
- 描绘用户真实痛点场景
- 让读者"对，我就是这样"

**Layer 2：解决方案（中段）**
- 自然引出产品
- 讲"我是怎么用的"+"效果是什么"
- 具体到使用步骤和真实感受

**Layer 3：转化引导（结尾）**
- 不硬推
- "如果你也有 X 困扰，可以试试"
- 给一个明确的下一步（链接/优惠/咨询）

### 合规要点

- 标明"推广"/"广告"
- 不用绝对化用语（"最好的""100%有效"）
- 不虚假承诺效果
- 医疗/金融类敏感词规避

---

## 六、通用输出规范

1. **先策划后写作** — 任何长文先出策划方案，用户确认再写
2. **字数遵守指令** — 用户指定字数就死守，不擅自加长或缩短
3. **不编造数据** — 引用必须有出处，不确定的标"据公开报道"
4. **不堆砌专业词** — 大众内容用大白话
5. **交付即停** — 完成后不展开额外内容
