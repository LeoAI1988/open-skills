# 中文内容创作

## 先确认任务

明确受众、发布平台、目标、素材范围、字数、语气和交付格式。信息不足但不影响方向时采用合理默认值；会改变事实或立场时再询问。

## 原创长文

1. 找到具体受众的真实问题，不从空泛趋势开场。
2. 提炼一个有证据支撑的差异化角度。
3. 先给标题、核心观点和结构；用户要求直接写时可跳过确认。
4. 按“场景钩子 → 冲突 → 分析 → 方案 → 行动”推进。
5. 每个重要事实标明来源；不确定内容明确标注，不编造数据、案例或引语。

## 基于参考材料改写

先确认材料可被使用。学习其主题、信息结构和传播机制，不复制独特表达、案例、比喻或连续段落，也不模仿在世作者的可识别个人风格。

工作流：

1. 拆解有效机制：开头、论证链、情绪节奏、证据和结尾。
2. 保留可验证的事实与必要出处。
3. 用新的角度、结构、语言和素材重写。
4. 对照原文检查是否存在近似表达或缺失署名。

## 去 AI 味与口语化

重点检查：

- 空洞开场和过度过渡句；
- 机械的“首先、其次、最后”；
- 长句堆砌和同义反复；
- 无依据的宏大结论；
- 过量术语、形容词和排比；
- 与说话者真实习惯不符的口头禅。

保留原意和事实，只调整节奏、句长、词汇和段落。需要模仿用户本人时，只依据用户主动提供的公开或自有样本，不写入姓名、联系方式或其他身份信息。

## 商业文案

采用“真实场景 → 问题 → 解决方式 → 证据 → 明确下一步”的结构。标识广告或合作关系，不使用虚假稀缺、伪造体验、绝对化效果或未经核验的医疗、金融承诺。

## 交付检查

- 字数、平台格式和用户指令一致；
- 标题与正文承诺一致；
- 事实、数字、引用均可追溯；
- 无个人姓名、联系方式、账号、凭证、本地路径或私人经历残留；
- 没有未经授权复制的表达；
- 交付成品，不附加无关说明。
