# 每日投资复盘 Skill

## 一、用途

盘后（15:00 后）系统化复盘当日操作，输出结构化报告。

**核心回答 4 个问题：**
1. 今天发生了什么？（行情+操作）
2. 操作对不对？（执行偏差）
3. 策略要不要调？（体系诊断）
4. 明天怎么干？（明日计划）

**触发：** 用户主动请求"启动复盘""出复盘""今日复盘"。**不自动跑**（不是定时 cron）。

## 二、数据采集

### 三源对照

| 优先级 | 数据源 | 用途 |
|--------|--------|------|
| 主 | 用户提供的截图（持仓+成交+自选股） | 真实数据 |
| 辅 | 腾讯行情 API | 实时/收盘价 |
| 补 | 当日新闻（7 维搜索） | 行情驱动因素 |

### 必采数据

**用户截图 OCR：**
- 持仓明细（标的/数量/成本/现价/盈亏%）
- 总资产/市值/可用资金
- 当日成交记录

**腾讯 API：**
- 大盘指数（沪指/深成指/创业板/科创 50）
- 持仓+候选标的收盘价
- 港股/美股联动（如有）

**新闻 7 维：**
1. 产业政策
2. 机构观点
3. 产业链动态
4. 海外映射
5. 资金流向
6. 风险提示
7. 反向搜索（看空理由）

### 截图 OCR 注意

- 用 GLM-5V-Turbo 或同等 vision 模型
- **不用 tesseract**（小数点容易错）
- OCR 成本价经常漂移（显示建仓初价/FIFO 重算），以加权成本为准

## 三、报告框架

### 3.1 核心结论（前置）

**最重要的 1-3 句话放最前面。**

```markdown
## 🎯 核心结论

[一句话总结今日操作对错 + 明日方向]
```

### 3.2 持仓真相表

```markdown
## 📊 持仓真相

| 标的 | 代码 | 数量 | 成本(OCR) | 加权成本 | 现价 | 盈亏% | 仓位% |
|------|------|------|----------|---------|------|-------|-------|
```

**关键：** 必须同时给 OCR 成本和加权成本（防止 OCR 漂移误导）。

### 3.3 当日操作记录

```markdown
## 📋 当日操作

| 时间 | 标的 | 方向 | 价格 | 数量 | 金额 | 触发原因 |
|------|------|------|------|------|------|---------|
```

### 3.4 大盘与板块

```markdown
## 🌐 大盘与板块

### 指数
| 指数 | 收盘 | 涨跌% |
|------|------|-------|

### 板块异动
- 强势板块：...
- 弱势板块：...
- 涨停/跌停：...
```

### 3.5 三市场链传（A 股/美股/港股）

```markdown

1. [标的] [操作] [触发条件]
2. ...

### 关注事件
- [事件 1]
- [事件 2]
```

## 四、CESMV 五维评分（可选）

对每个持仓按 5 维评分（每维 0-100）：

| 维度 | 含义 |
|------|------|
| C (Chain) | 产业链位置（上游/中游/下游） |
| E (Expectation) | 市场预期（一致/分歧） |
| S (Sentiment) | 情绪面（恐慌/贪婪） |
| M (Money) | 资金面（流入/流出） |
| V (Valuation) | 估值（高/低/合理） |

总分 = 加权平均。低于 60 分考虑减仓，高于 80 分考虑加仓。

## 五、SPI 卖方压力指数（可选）

```python
SPI = (涨停板数量 + 连板股数量 + 涨幅>5%股数量) / 总股票数
```

- SPI > 8/10：卖方压力极高，准备兑现
- SPI 3-8：中性
- SPI < 3：卖方压力低，可持有

## 六、执行流程

### Step 1：用户触发

用户说"启动复盘"→ 确认开始。

### Step 2：采集数据

- 索取截图（持仓+成交+自选股）
- 拉腾讯 API 收盘价
- 7 维搜索新闻

### Step 3：分析

- 操作对错
- 时机把握
- 策略偏离
- 明日催化

### Step 4：生成报告

按"三、报告框架"输出。

### Step 5：存档

- 写入笔记系统（量化笔记库）
- 追加到 L2 工作上下文
- 推送用户

## 七、常见坑

| 坑 | 后果 | 规避 |
|----|------|------|
| 没拉实时就用 OCR | 价格偏差 | 必拉腾讯 API |
| OCR 成本漂移没校验 | 决策错误 | 同时给加权成本 |
| 只说利好不说利空 | 踏空风险 | 必走反向搜索 |
| 报告写太长 | 用户不看 | 核心结论前置 |
| 明日计划太模糊 | 不可执行 | 必含触发条件 |
| 不存档 | 下次找不到 | 必写入笔记系统 |

## 八、输出规范

1. **核心结论前置** — 最重要的 1-3 句放最前
2. **数据必带时间戳** — 每个数据点标注时间
3. **必走反向搜索** — 不能只有利好
4. **明日计划必含触发条件** — 不写"关注 X"，写"X 跌破 Y 就买"
5. **必存档** — 写入笔记系统
6. **不恢复旧状态** — Cron 永远不恢复，除非用户明确要求
