# 免费公开搜索兜底

## 目标

在不依赖付费搜索额度的前提下，组合当前可用的公开搜索、官方站点、开放数据库和浏览器能力。来源数量服从问题难度，不为凑数量搜索低质量页面。

## 来源选择

| 场景 | 优先来源 |
|---|---|
| 政策与规则 | 官方机构、法规和平台帮助中心 |
| 技术与开源 | 官方文档、代码仓库、包注册表、技术社区 |
| 学术 | 论文索引、预印本、作者机构页面 |
| 行业与产品 | 公司官网、公告、权威媒体、评测 |
| 中文内容 | 原始发布页、平台搜索、公开转载线索 |

## 执行流程

1. 明确问题、时间范围、地区、语言和需要的证据类型。
2. 先找一手来源，再用独立来源补充或反驳。
3. 并行查询多个不同类型来源；单个来源失败不阻塞全部结果。
4. 对关键结果读取正文，不只看标题和摘要。
5. 按事实、观点和推断分类，去重同源转载。
6. 标注发布日期、访问日期、链接和可信度。
7. 给出未覆盖范围和仍需核验的点。

## 全文读取

动态页面优先使用浏览器读取渲染后的正文。遇到登录墙、付费墙、robots 限制或不可访问页面时说明限制，不绕过访问控制。无法读全文时可以保留摘要线索，但必须标注“未读取全文”。

## 输出格式

```markdown
## 结论
## 搜索范围与截止时间
## 已确认事实
## 不同来源的观点
## 反向证据或冲突
## 未覆盖项
## 来源
```

## 失败处理

- 工具不可用前先做一次轻量实测；
- 来源不足时降低置信度，不用已有知识冒充实时搜索；
- 需要登录或用户授权时停在授权边界；
- 不记录账号、Cookie、密钥、私人链接或本地路径。
