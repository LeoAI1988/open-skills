# 香港身份服务电影感广告创意

## 边界

使用原创的电影叙事结构，不复刻具体影片镜头、角色、台词、配乐或可识别人物。身份、教育、税务、医疗和居留规则必须在制作时核验，不把广告创意当作法律承诺。

## 先确定卖点

每条广告只承载一个经核验的主题，例如：

- 教育路径与选择空间；
- 家庭长期规划；
- 居留安排和时间成本；
- 跨境生活便利性；
- 服务流程和常见误区。

不使用“保证获批”“一定永居”“绝对省税”等表述。

## 原创场景原型

| 原型 | 情绪 | 适合主题 |
|---|---|---|
| 交接一件旧物 | 传承、责任 | 家庭长期规划 |
| 两扇门的选择 | 犹豫、机会 | 教育或路径比较 |
| 深夜整理文件 | 压力、确定性 | 申请流程与准备 |
| 车站或渡口告别 | 距离、连接 | 跨境生活安排 |
| 餐桌上的安静决定 | 家庭、共识 | 多成员决策 |

从原型出发生成新人物、新场景和新台词，不写真实姓名、联系方式或客户经历。

## 工作流

1. 核验要表达的政策事实和有效日期。
2. 选择一个原创场景原型和主要情绪。
3. 写一句事实主张、一句情绪表达和一个行动指引。
4. 生成 6–10 镜分镜，标注景别、动作、光线、声音和时长。
5. 生成图像或视频提示词，避免名人、现有角色和商标元素。
6. 检查平台广告规则、版权、隐私和事实准确性。
7. 用户确认后再制作或发布。

## 提示词模板

```text
比例：[16:9 / 4:3 / 9:16]
场景：[原创地点与时间]
人物：[匿名角色、服装、动作，不指定真实人物]
镜头：[景别、机位、运动、景深]
光线与色彩：[具体描述]
道具：[承载情绪的日常物件]
台词：[原创短句]
事实字幕：[已核验内容与日期]
限制：[无名人、无现有角色、无商标、无联系方式]
```

## 交付检查

- 创意与卖点一一对应；
- 政策事实有当前来源；
- 无现成电影台词、镜头、人物或配乐；
- 无姓名、客户案例、联系方式和可识别家庭信息；
- 风险提示和行动指引清楚。
