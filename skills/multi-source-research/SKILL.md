# 多源投资研究

## 边界

提供信息检索和证据整理，不保证数据实时性，不替代持牌投资建议。持仓、账户和交易数据按敏感信息处理，不写入公开产物。

## 来源优先级

1. 监管机构、交易所、上市公司公告与正式财报；
2. 官方统计、指数编制方和基金文件；
3. 可靠行情提供方与主流财经媒体；
4. 行业数据库、研究报告和公司访谈；
5. 社交媒体和论坛，只作线索，不单独作为结论。

价格、财务数字和重大事件尽量由两个独立来源交叉验证。两个页面转述同一篇稿件不算两个独立来源。

## 执行流程

### 1. 定义问题

明确标的、市场、代码、时间范围、币种、复权口径、目标数据和用途。代码相似或市场不明时先确认，避免查错标的。

### 2. 先查一手资料

优先定位公告、财报、交易所数据、监管文件或基金说明书。记录标题、发布日期、覆盖期和链接。

### 3. 补充行情与解释

使用当前环境可用的行情、搜索和浏览器工具。工具名称、账号、密钥和本地脚本位置不写死；调用前检查可用性和数据时间戳。

### 4. 深读来源

对关键链接读取正文、表格和脚注，不只依赖搜索摘要。遇到登录墙、付费墙或访问失败时说明覆盖边界，不绕过访问控制。

### 5. 交叉验证

对每个关键结论记录：

| 结论 | 来源 A | 来源 B | 时间 | 是否冲突 | 置信度 |
|---|---|---|---|---|---|

出现冲突时检查币种、单位、复权、报告期、盘前盘后和更新时间，不用“多数票”替代口径核对。

### 6. 反向搜索

主动寻找与初始判断相反的证据，包括：风险提示、监管变化、竞争格局、客户集中、资本开支、现金流、估值和潜在催化落空。

### 7. 输出

```markdown
## 一句话结论
## 研究范围与截止时间
## 已确认事实
## 支持证据
## 反向证据与风险
## 数据冲突或空白
## 来源表
```

把事实、市场观点和分析判断分开。任何“已发生”“已公布”“当前价格”都必须能回到带时间戳的来源。

## 工具失败

在说工具不可用前做一次轻量实测。若所有实时渠道失败：

1. 列出已尝试的渠道和错误；
2. 标明哪些信息仍可从已有材料确认；
3. 给出知识截止或数据截止时间；
4. 请用户提供授权来源或等待服务恢复；
5. 不把训练知识冒充实时结果。

## 隐私与安全检查

- 不包含 API 密钥、访问令牌、客户端 ID 或私有接口；
- 不包含本地路径、服务器地址、内部笔记 ID 或私人链接；
- 不公开姓名、账户号、联系方式、精确持仓或资产；
- 不把研究结论写成保证收益或自动下单指令。
