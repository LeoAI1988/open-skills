# 投资绩效分析

## 边界与隐私

本 Skill 用于事后统计与教育性分析，不保证未来收益。账户数据、截图、成交和资产金额属于敏感信息；只在授权范围内处理，公开产物使用汇总或匿名数据。

## 输入

- 统计起止日期与市场；
- 账户快照和完整成交记录；
- 入金、出金、分红、税费和利息；
- 基准及其选择理由；
- 策略变更日期；
- 数据缺失或口径变化说明。

冲突优先级通常为：原始交易或资金流水 > 经用户确认的账户快照 > 复盘笔记 > OCR 或推算值。所有推算必须标记。

## 计算原则

### 现金流剥离

入金和出金不是收益。简单盈亏可写为：

```text
净盈亏 = 期末资产 - 期初资产 - 净入金
净入金 = 入金 - 出金
```

跨期比较优先使用时间加权收益率；需要反映个人资金实际回报时使用资金加权收益率，并说明现金流日期。不要在存在大额现金流时直接用期初、期末资产计算年化。

### 链式核对

逐日或逐期检查：

```text
预期资产 = 上期资产 + 本期盈亏 + 本期净入金
差额 = 本期资产 - 预期资产
```

差额超过容差时检查费用、分红、币种、估值时点、复权口径、隔夜变动和数据错误。

### 风险指标

在数据充分时计算：累计收益、时间加权收益、资金加权收益、最大回撤、波动率、胜率、盈亏比、换手、仓位利用率和相对基准表现。样本不足时不输出伪精确指标。

## 执行流程

1. 确认日期、账户口径、现金流、基准和策略分段。
2. 统一币种、时区、复权和费用口径。
3. 重建资产与交易时间线。
4. 找出断点、重复记录和缺失区间。
5. 计算指标，并给出数据覆盖率和可信度。
6. 分析计划执行、仓位、止损、追涨和集中度偏差。
7. 输出改进优先级，不直接生成未经用户确认的买卖指令。

## 报告结构

```markdown
## 结论摘要
## 数据范围、口径与覆盖率
## 现金流与资产核对
## 收益与风险指标
## 基准和策略分段对比
## 主要贡献与拖累
## 执行偏差
## 改进优先级
## 存疑数据与待确认项
```

## 决策视角

用角色化问题检查盲区，不引用具体人物：

- 周期位置：当前结果来自趋势、估值还是短期情绪；
- 风险分散：相关性、集中度和尾部风险是否可控；
- 认知完整性：每个持仓的原始假设是否仍成立；
- 逆向验证：如果结论错误，最可能漏掉什么；
- 长期视角：当前行为是否可持续复用。

## 交付检查

- 现金流未被计入收益；
- 公式、基准、币种和年化口径已说明；
- 数据覆盖不足时已降级结论；
- 没有姓名、账户号、联系方式、精确私人资产或内部来源 ID；
- 结论基于记录，不用结果倒推当时理由。
