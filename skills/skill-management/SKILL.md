# Skill 生命周期管理

## 创建或更新

1. 明确触发场景、输入、输出、步骤和失败模式。
2. 使用小写字母、数字和连字符命名目录。
3. 在 `SKILL.md` frontmatter 中提供清晰的 `name` 和 `description`。
4. 主文件只保留核心流程；详细资料放在 `references/`，重复脚本放在 `scripts/`。
5. 为界面生成 `agents/openai.yaml`，确保描述与主文件一致。
6. 删除占位文件和与执行无关的说明文档。

标准结构：

```text
skill-name/
├── SKILL.md
├── agents/
│   └── openai.yaml
├── scripts/       # 可选
├── references/    # 可选
└── assets/        # 可选
```

## 安全与隐私审查

检查所有文本、脚本、资源和压缩包：

- 硬编码密钥、令牌、Cookie、密码和客户端 ID；
- 姓名、昵称、联系方式、账户号、内部 ID 和私人链接；
- 本地路径、服务器地址、家庭或客户信息；
- 未声明的网络请求和文件写入；
- 动态执行、混淆代码和不必要的安装命令；
- 过度授权、不可逆操作和未经确认的外部发布；
- 许可证、版权和第三方资源来源。

正则扫描只能发现明显命中，必须再做语义审查。

## 验证

- frontmatter 可解析，目录名与 `name` 一致；
- 引用文件存在且路径正确；
- 脚本在代表性输入上运行；
- 界面描述与 Skill 内容一致；
- 压缩包中的文件与源目录逐字节一致；
- ZIP 内使用标准正斜杠路径；
- 没有缓存、临时文件或系统文件。

## 安装

1. 从可信来源取得 Skill 包。
2. 审查后再解压。
3. 放入当前环境配置的 Skill 目录。
4. 验证 `SKILL.md` 位于 Skill 根目录。
5. 用一个真实触发示例测试加载和输出。
6. 报告安装位置、版本、验证结果和已知限制。
