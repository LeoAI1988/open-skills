# 社交媒体发布 Skill

统一管理内容发布与素材采集。

## 一、小红书发布

**触发：** "帮我发到小红书""发笔记""定时明天 9 点发"

### 发布流程

1. **内容验证**
   - 标题 ≤ 20 字（超限被截断）
   - 正文 200-800 字（建议）
   - 图片：1-9 张，单张 ≤ 20MB
   - 敏感词检查（医疗/金融/政治）

2. **话题生成**
   - 根据内容生成 3-5 个话题标签
   - 格式：`#话题1 #话题2`

3. **预览确认**
   - 展示标题/正文/图片/话题/定时时间
   - **等用户确认后再发布，不要擅自推送**

4. **执行发布**
   - 通过浏览器自动化执行
   - 依赖已登录的浏览器会话

5. **失败处理**
   - 给出手动回退指引（打开 App + 复制内容）

### 发布前检查清单

- [ ] 标题 ≤ 20 字
- [ ] 图片 1-9 张
- [ ] 无敏感词
- [ ] 话题已生成
- [ ] 用户已确认

## 二、微信公众号发布

**触发：** "发公众号""帮我排版""发布文章"

### 排版规范

| 元素 | 规格 |
|------|------|
| 正文字号 | 16px |
| 行间距 | 1.75 |
| 段间距 | 25px |
| 引用块 | 浅色背景 |
| 图片 | 居中，与正文间距 15px |
| 代码块 | 深色背景 + 等宽字体 |

### 关键约束

- **正文不要出现 Markdown 标记**（`**加粗**`、`# 标题`）— 格式由排版引擎转换
- **封面图**：尺寸符合平台要求，提前准备
- **配图**：优先用 HTML/CSS 渲染截图，避免直接截图

### 流程

1. 检查正文格式（无 Markdown 残留）
2. 应用排版规则
3. 插入配图
4. 用户预览确认
5. 发布
6. 存档到笔记系统

## 三、内容抓取（素材采集）

**触发：** "抓取这个链接""采集这篇内容""把这个网页的内容取下来"

### 支持平台

| 平台 | 方法 | 注意 |
|------|------|------|
| 小红书 | 浏览器 | 登录墙、内容截断 |
| 微博 | 浏览器 | 长文展开、评论区 |
| 知乎 | 浏览器 | 全文 + 评论 |
| B 站 | 浏览器 | 视频简介 + 评论 |
| X/Twitter | 浏览器/API | 推文 + 线程 |

### 抓取流程

1. **识别平台** → 选择策略
2. **处理登录/截断** → 自动展开全文
3. **结构化提取** → 标题/正文/作者/发布时间/评论
4. **输出 JSON** → 供下游内容创作使用

### 单页 SPA 特殊处理

部分平台（如券商 App、新闻 H5）返回的是 3-4KB 的 JS 空壳，直接 curl 拿不到内容。

**正确做法：**
- 用 `browser_navigate` 加载页面
- 等待 JS 渲染完成（3-5 秒）
- 用 `innerText` 提取渲染后的 DOM 文本
- 不要直接 curl 后报"读不了"

## 四、通用规则

1. **先预览后发布** — 用户不确认前不推送任何内容
2. **失败有回退** — 始终提供手动发布的指引
3. **内容合规** — 发布前检查敏感词和平台规则
4. **定时发布** — 支持指定时间（受平台限制）
5. **素材归档** — 抓取的内容存入笔记系统，方便后续复用
