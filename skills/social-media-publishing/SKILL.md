# 社交媒体发布与素材采集

## 发布边界

发布、定时和修改线上内容属于外部操作。先展示最终标题、正文、媒体、标签、账号和时间；用户明确确认后才能执行。不要导出登录凭证、Cookie 或私信数据。

## 发布流程

1. 确认目标平台、账号、内容类型和发布时间。
2. 按平台当前规则检查标题、正文、图片、视频、封面和话题。
3. 执行事实、版权、广告标识、敏感词和隐私检查。
4. 生成完整预览，列出会公开显示的全部内容。
5. 等用户确认。
6. 通过已登录的官方网页或授权接口发布。
7. 核验发布状态、链接、时间和可见范围。
8. 只归档公开稿和必要元数据，不保存登录信息。

平台限制会变化，不在 Skill 中写死标题长度、图片数量或文件大小；执行时查看官方发布页面或帮助中心。

## 公众号排版

- 正文优先清晰、可读和移动端友好；
- 发布前移除 Markdown 残留；
- 图片、引用和代码块保持一致间距；
- 封面、摘要、作者署名和原文链接单独核对；
- 用户确认文字定稿后再排版和发布。

## 素材采集

只采集用户授权或公开可访问的内容，遵守登录、付费、robots、版权和平台规则。

1. 识别页面类型和访问边界。
2. 动态页面使用浏览器读取渲染后的正文。
3. 提取标题、正文、发布日期、公开来源链接和必要媒体说明。
4. 区分原文、评论和自动摘要。
5. 记录出处，不批量采集私人资料或绕过访问控制。

## 失败处理

- 登录失效：让用户重新登录，不索取密码；
- 上传能力不可用：交付整理好的文件和手动步骤；
- 定时功能不支持：说明平台限制，不伪装成功；
- 发布结果不确定：保持内容不变，先检查线上状态，避免重复发布。

## 隐私检查

公开内容不得意外包含姓名、电话、邮箱、微信号、地址、定位、订单号、未成年人信息、后台截图、内部 ID 或其他账号资料。
