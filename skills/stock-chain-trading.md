# AI 产业链链传交易策略 Skill

## 一、用途

为个人投资者提供基于产业链传导（链传）的交易策略框架。核心方法：
- **CESMV 五维评分** — 选标的
- **SPI 卖方压力指数** — 择时
- **链传映射** — 判断板块联动
- **仓位指挥棒** — 控风险

**适用市场：** A 股为主，港股/美股联动参考。

## 二、核心理念

### 理念 1：产业链联动 > 单股分析

同产业链的股票会联动（同涨同跌）。做单股分析前，先判断整个产业链的方向。

### 理念 2：卖方压力 > 买方动能

当多数人想卖时，价格必跌。SPI 衡量卖方压力，比看资金流入更准。

### 理念 3：仓位指挥棒 > 个股选择

选对股但仓位错（满仓 vs 空仓）= 结果差异 10 倍。仓位是第一要务。

## 三、CESMV 五维评分

### 五维定义

| 维度 | 含义 | 数据源 |
|------|------|--------|
| **C (Chain)** | 产业链位置 | 上游/中游/下游 |
| **E (Expectation)** | 市场预期 | 券商研报一致预期 |
| **S (Sentiment)** | 情绪面 | 论坛/社交媒体/换手率 |
| **M (Money)** | 资金面 | 北向/南向/主力净流入 |
| **V (Valuation)** | 估值 | PE/PB/PS 历史分位 |

### 评分标准（0-100）

| 分数 | 含义 | 操作 |
|------|------|------|
| 80-100 | 优秀 | 加仓 |
| 60-80 | 良好 | 持有/小买 |
| 40-60 | 中性 | 观望 |
| 20-40 | 偏弱 | 减仓 |
| 0-20 | 差 | 清仓 |

### 加权总分

```
总分 = C×0.2 + E×0.2 + S×0.15 + M×0.25 + V×0.2
```

资金面权重最高（0.25）— 因为资金是最终驱动力。

## 四、SPI 卖方压力指数

### 计算公式

```python
涨停板数 = count(涨幅 ≥ 9.9%)
连板股数 = count(连续 ≥ 2 天涨停)
大涨股数 = count(涨幅 > 5%)

SPI = (涨停板数 + 连板股数 + 大涨股数) / 总股票数 × 10
```

### 分级

| SPI | 级别 | 含义 | 操作 |
|-----|------|------|------|
| ≥ 8 | 极高 | 板块高潮，即将回调 | 减仓 30-50% |
| 5-8 | 高 | 获利盘堆积 | 准备兑现 |
| 3-5 | 中 | 正常 | 持有 |
| 1-3 | 低 | 情绪低迷 | 可低吸 |
| < 1 | 极低 | 恐慌底部 | 抄底 |

### SPI 与 CESMV 冲突优先级

**SPI 优先。** CESMV 再好，SPI 极高 = 必减仓。

## 五、12 节点链传映射

### 半导体/AI 产业链链传图

```
【上游】                  【中游】                  【下游】
设备                     设计                     AI 服务器
├─ 光刻机                ├─ 芯片设计              ├─ 整机
├─ 刻蚀设备              ├─ EDA 工具              ├─ 散热
├─ 薄膜沉积              └─ IP 授权               └─ 电源
└─ 测试设备
                          制造                     云计算
材料                     ├─ 晶圆代工              ├─ IDC
├─ 硅片                  ├─ IDM                   ├─ 光模块
├─ 光刻胶                └─Foundry                └─ 交换机

                          ├─ 先进封装              ├─ 大模型
设备零件                  ├─ 传统封装              ├─ AI 应用
├─ 阀门                  └─ 测试                  └─ 终端设备
├─ 真空泵
└─ 机械手
```

### 链传规则

1. **上游先行** — 设备/材料先涨 → 中游制造跟涨 → 下游应用最后
2. **板块共振** — 同板块多只股票同涨同跌 = 板块行情，不是个股行情
3. **海外映射** — 美股费城半导体指数 T-1 涨跌 → A 股半导体 T0 跟
4. **链传中断** — 上游涨但中游不跟 = 链传中断，警惕假突破

### 9:20 竞价复核

每天 9:20 拉一次链传代表股的竞价数据：
- 上游代表 1 只
- 中游代表 1 只
- 下游代表 1 只

判断当日链传方向。

## 六、抄底策略（4 雷达）

### 4 个触发雷达（任一命中考虑抄底）

| 雷达 | 触发条件 |
|------|---------|
| **恐慌底** | 板块单日跌 ≥ 5%，SPI < 1 |
| **政策底** | 重大利好政策（降准/降息/产业政策） |
| **业绩底** | 龙头公司业绩超预期 |
| **技术底** | 关键支撑位企稳（如 60 日线/前期低点） |

### 抄底铁律

1. **不追竞价** — 竞价时挂限价单，不等市价
2. **板块共振期不追** — 多只股票同时暴跌 = 板块问题，不抄个股
3. **等企稳 15 分钟** — 开盘 15 分钟后确认企稳再买
4. **分批进** — 不一把梭，先 50%，回调再加

### 抄底放弃条件

- 大盘开盘即跌破关键支撑且无反弹
- 隔夜美股继续暴跌 > 5%
- 目标股开盘跳空 > 5%（等回落）

## 七、止损三级分类

| 级别 | 触发 | 操作 |
|------|------|------|
| **A 级（硬止损）** | 跌破预设止损线（如 -8%） | 立即市价清仓 |
| **B 级（软止损）** | 基本面恶化（业绩/政策反转） | 当日清仓 |
| **C 级（预警）** | 跌幅 ≥ 5% 但未破止损线 | 观察不加仓 |

**铁律：** A 级止损不犹豫。到了就割，不抱幻想。

## 八、仓位指挥棒

### 整体仓位 × 信心档位

| 信心档位 | 最大仓位 | 适用 |
|---------|---------|------|
| 高（CESMV ≥ 80） | 60% | 强势主线 |
| 中（CESMV 60-80） | 40% | 正常持仓 |
| 低（CESMV 40-60） | 20% | 试探 |
| 极低（CESMV < 40） | 0% | 空仓 |

### 单标的加仓上限

| 档位 | 单标的上限 |
|------|-----------|
| 主线龙头 | 40% |
| 主线非龙头 | 25% |
| 非主线 | 15% |

### 空仓期操作

空仓时挂条件单（限价单）等回踩：
- 建仓价 = 现价 × 0.92（回调 8%）
- 止损价 = 建仓价 × 0.92
- 不追竞价
- 板块共振期不追（多个候选同时触发 = 板块问题）

## 九、周五逻辑校正

### 周五减仓铁律

| 场景 | 操作 |
|------|------|
| 持仓涨幅 ≥ 5% | 周五必减仓 30% |
| 持仓涨幅 ≥ 10% | 周五必减仓 50% |
| 重大事件前（FOMC/数据） | 周五必空仓或对冲 |

### 4 红旗信号（任一亮起 = 不抄底）

1. 连续 2 日 ≥ 5% 大涨
2. SPI ≥ 8
3. 周五（法定获利了结日）
4. 重大不确定事件在周末

## 十、必做清单输出规范

### 必含 3 列

```
| 标的 | 代码 | 建仓价 | 现价 | 偏离% | 股数 | 金额 | 止损 | 触发? |
```

**铁律：** 偏离 > 3% 必标"❌ 失效需重定"。

### 三选一推荐模板（偏离过大时）

```markdown
**X 标的偏离 Y%，3 选 1：**
A. 重新挂单 @ 现价附近（接受当前价）
B. 等回踩支撑位（X 元）
C. 取消该标的，换其他
```

## 十一、执行流程

### 盘前（07:30）

1. 拉竞价数据
2. 7 维搜索新闻
3. 生成晨报（必做清单+触发价）

### 盘中（9:30-15:00）

- 实时监控持仓+候选
- 触发条件单 → 提醒用户
- 异常波动 → 告警

### 盘后（16:00）

- 启动复盘 skill
- 生成复盘报告
- 明日计划

## 十二、常见坑

| 坑 | 后果 | 规避 |
|----|------|------|
| 只看 CESMV 不看 SPI | 高位站岗 | SPI 优先 |
| 追竞价买入 | 当日套牢 | 限价不追 |
| 板块共振期抄底 | 继续暴跌 | 等企稳 |
| 周五满仓过周末 | 周末利空爆雷 | 周五减仓 |
| 止损犹豫 | 小亏变大亏 | 到价就割 |
| 仓位与信心不匹配 | 高信心低仓位=踏空；低信心高仓位=巨亏 | 按指挥棒 |
| 触发价长期不更新 | 偏离 10%+ | 偏离 > 3% 必重定 |
| 限价单不含股数 | 无法执行 | 必含股数+金额 |

## 十三、输出规范

1. **结论前置** — 核心判断放最前
2. **必做清单含触发价** — 不写"关注 X"，写"X 跌破 Y 就买 N 股"
3. **条件单必含股数+金额** — 缺股数 = 不合格
4. **偏离 > 3% 必标失效** — 不藏不掩
5. **SPI 与 CESMV 冲突时 SPI 优先** — 明确说明
6. **空仓期继续监控** — 不因为空仓就不出报告
7. **必走反向搜索** — 不能只有利好
