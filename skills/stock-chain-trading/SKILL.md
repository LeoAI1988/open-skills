# 产业链交易研究框架

## 边界

本 Skill 是研究和风险管理模板，不构成个性化投资建议。所有分数、阈值和仓位仅作可调整的分析参数；具体交易必须由用户结合自身风险承受能力确认。

## 五维评分

| 维度 | 问题 | 常见证据 |
|---|---|---|
| 产业链 | 标的处于哪个环节，议价能力如何 | 订单、产能、客户、供应关系 |
| 预期 | 市场已计入什么，分歧在哪里 | 指引、估值、分析预期 |
| 情绪 | 当前交易是否拥挤 | 涨跌分布、换手、波动、讨论热度 |
| 资金 | 成交和持仓变化是否支持判断 | 成交量、资金结构、机构披露 |
| 估值 | 当前价格需要怎样的增长才能成立 | 历史分位、同业、现金流情景 |

为每维定义 0–100 分及证据，再按任务设置权重。缺数据时降低置信度，不用主观印象补满分数。

## 产业链映射

按实际行业建立：

```text
原材料/设备 → 设计/制造 → 模组/系统 → 渠道/应用 → 终端需求
```

对每个环节记录代表标的、领先或滞后关系、关键数据和可能的传导中断点。相关性不等于因果；海外市场、汇率和时区差异需单独核验。

## 市场压力指标

可用涨跌分布、涨停/跌停、成交集中度、波动率、换手和融资变化组合成压力指标。公式必须：

- 与“压力”方向一致；
- 使用同一市场和时间窗口；
- 经过历史样本回测；
- 不把一个未经验证的阈值写成硬性买卖命令。

## 条件化计划

为每个候选写三类条件：

| 类型 | 内容 |
|---|---|
| 进入前提 | 需要确认的基本面、价格和市场条件 |
| 失效条件 | 哪些事实会推翻原始假设 |
| 风险限制 | 最大可承受损失、流动性和集中度限制 |

不用“必涨”“抄底”“到价必买”等确定性措辞。价格偏离原计划时重新评估，不自动追价。

## 执行流程

1. 确认标的、市场、期限和用户风险边界。
2. 建立产业链图与关键领先指标。
3. 收集五维证据并标注时间。
4. 运行反向搜索，寻找链传中断和估值失效理由。
5. 生成偏强、中性、偏弱三种情景。
6. 写入待用户确认的观察清单和风险条件。
7. 盘后以真实成交和结果复盘，不用事后信息改写原计划。

## 输出模板

```markdown
## 产业链结论
## 数据范围与时间
## 五维评分及证据
## 跨环节传导与中断点
## 反向证据
## 三种情景
## 风险限制与待确认项
```
