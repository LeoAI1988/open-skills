# 腾讯生态创作者账号矩阵 · 全栈决策 Skill

## 一、用途

为内容创作者/知识付费从业者提供腾讯生态（视频号+公众号+小店）的账号矩阵规划、认证路径、营业执照选择、税务优化的全流程决策支持。

**政策时效：** 2024-2027 年现行优惠政策。

---

## 二、6 个核心分水岭

### 2.1 一个人能认证几个？

| 主体 | 视频号 | 公众号 |
|------|--------|--------|
| 个人身份证 | **1 个**（终身） | 1 个（终身） |
| 企业主体 | 50 个 | 50 个 |

### 2.2 视频号 + 公众号联动条件

- 同名 + 同一主体（个人绑身份证，企业绑营业执照）
- 后台"绑定公众号" → 公众号文章出现在视频号主页
- 未认证的公众号也能绑（但带"-"后缀，曝光受限）

### 2.3 开店铺/挂小黄车条件

- **个人号**：不能开自己的小店，只能做商品橱窗挂第三方商品（CPS 抽佣）
- **企业号**：必须 + 类目资质
- 卖课程/咨询服务：营业执照需"教育咨询/信息技术咨询/技术服务/软件开发"之一

### 2.4 视频号小店保证金（2024-2025）

| 类目 | 普通店（个体户） | 旗舰店/专卖店 |
|------|-----------------|--------------|
| 教育/培训 | **1000-5000** | 30000-50000 |
| 知识付费/虚拟课程 | **1000** | 5000 |
| 咨询服务 | **1000** | 5000 |
| 软件/技术服务 | 2000-5000 | 20000-30000 |

### 2.5 平台佣金

- 视频号小店技术服务费：1%-5%
- 教育类目 2% · AI 工具/技术服务 2-3%

### 2.6 经营范围与商品关系

- 卖**实物商品**：经营范围必须匹配类目
- 卖**虚拟课程/咨询/服务**：仅需"教育咨询/信息技术咨询/技术服务/软件开发"之一
- 不强制科技企业，但有相关字眼审核更快

## 三、认证路径决策

### 3.1 个人认证能做什么

- ✅ 视频号商品橱窗（挂第三方商品，抽佣模式）
- ❌ 不能开自己的小店
- ❌ 不能挂自己的商品/课程
- ❌ 不能用"教育培训"类目（系统引导企业认证）

### 3.2 企业认证能做什么

- ✅ 开通视频号小店（自己的店铺）
- ✅ 上架自有商品
- ✅ 流量权重高 30-50%
- ✅ 提现到法人个人卡（个体户）或对公账户（有限公司）

### 3.3 决策铁律

- **卖自己的课 = 必须企业认证**（没有第二条路）
- 个人认证 + 流量大 = 系统自动提醒做企业认证
- 个人身份证每年限 1 个视频号个人认证（终身 1 个公众号）

## 四、营业执照决策（3 选 1）

### 4.1 三种主体类型

| 类型 | 税务 | 到账 | 风险 | 注销 |
|------|------|------|------|------|
| **个体工商户** | 核定征收 0.5%-2.5% | **个人银行卡** ✅ | 无限连带责任 | 简单 3-7 天 |
| 有限公司（小规模） | 查账 9-15% | 对公账户 | 有限责任 | 1-2 个月 |
| 有限公司（一般纳税人） | 13% 增值税+企税 | 对公账户 | 有限责任 | 1-2 个月 |

### 4.2 经营范围推荐（3-5 个最稳）

**套餐 A（教育方向）**：
```
1. 教育咨询服务（主）
2. 信息技术咨询服务
3. 互联网销售（除销售需要许可的商品）
4. 组织文化艺术交流活动
```

**套餐 B（科技方向·最匹配 AI 课）**：
```
1. 信息技术咨询服务（主）
2. 人工智能应用软件开发
3. 教育咨询服务
4. 互联网信息服务
5. 网络技术服务
```

**关键：** 经营范围数量不影响注册成本，但写多了不经营会被吊销。

## 五、税务精确对比（2024-2027 政策）

### 5.1 三大优惠政策

| 政策 | 有效期 |
|------|--------|
| 小规模增值税月销 ≤ 10 万 / 季销 ≤ 30 万 → 免征 | 2027.12.31 |
| 超出部分 3% 减按 **1%** | 2027.12.31 |
| 个体户经营所得 **≤ 200 万 → 减半征收** | 2027.12.31 |
| 小微企税 **≤ 300 万 → 5%** | 2027.12.31 |

### 5.2 关键分水岭

**核定征收（0.25%-0.6%）> 个体户查账（8-10%）> 公司分红（15.5%）**

**100-1000 万营收区间，个体户永远比公司划算。**

公司反超的唯一场景：不分红 + 利润再投资（15.5% → 4-5%，但钱在账上不是个人的）。

### 5.3 核定征收实操风险（2024 收紧）

⚠️ 2024 起核定征收大幅收紧：
1. 不能是空壳个体户 — 必须实际经营
2. 不能大额公转私 — 单笔 > 20 万、累计 > 50 万触发预警
3. 必须在税收园区注册 — 部分园区仍可申请
4. 不能开大量增值税专票 — 开了就转查账征收
5. 部分行业禁止核定（明星网红、直播带货）— **AI 课/教育咨询目前仍可**

**最优路径：** 税收园区（重庆/江西/湖北/河南）代办注册个体户 + 核定征收，1500-3000 元全包。

## 六、注册与运营成本

### 6.1 注册费

| 方式 | 价格 | 备注 |
|------|------|------|
| 自己办（电子化） | 0 元 | 90% 城市支持 |
| 代办公司 | 500-1500 元 | 含刻章+税务报到+银行开户 |
| 税收园区（含核定） | **1500-3000 元** | 注册+1 年代账打包 |
| 挂靠地址 | 0-2000 元/年 | 没商用地址要挂靠 |

### 6.2 每年记账报税

| 类型 | 月费 | 年费 |
|------|------|------|
| 个体户（核定） | 200-500 元 | **2400-6000 元** |
| 个体户（查账） | 300-600 元 | 3600-7200 元 |
| 有限公司（小规模） | 400-800 元 | 4800-9600 元 |

个体户比公司便宜 30-40%。

## 七、任务起点 Checklist

每次决策前必走：

```yaml
[ ] 1. 业务是什么？（AI 课/HK 身份/矩阵整合/纯卖课）
       → 业务决定经营范围 + 认证类型
[ ] 2. 现有营业执照的经营范围匹配吗？
       → 有 = 复用；没有 = 增项（500-1500 元）或新办
[ ] 3. 视频号目前什么认证？（个人 or 企业）
       → 个人卖自己的课 = 必转企业
[ ] 4. 预计年营收？
       → < 100 万 = 季销 30 万内免增值税
       → 100-1000 万 = 个体户 + 核定征收最优
       → > 1000 万 = 考虑公司化
[ ] 5. 是否需要 ICP / 融资 / 上市？
       → 需要 = 有限公司
       → 不需要 = 个体户（更省）
[ ] 6. 选代办 or 自己办？
       → 自己办 = 0 元，但搞定不了核定征收
       → 园区代办 = 1500-3000 元含核定，推荐
```

## 八、常见误区

| 误区 | 真相 |
|------|------|
| "个人认证能挂自己的课" | ❌ 个人只能挂第三方商品，自己课必须企业 |
| "个体户开不了小店" | ❌ 个体户和公司开店权限一样，只是结算到个人卡 |
| "经营范围越多越好" | ❌ 多写了不经营 = 被吊销，3-5 个最稳 |
| "核定征收随便办" | ❌ 2024 收紧，必须税收园区+实际经营+不能大额公转私 |
| "企业认证可以个人转" | ❌ 不能转，只能重新做（注销原账号） |
| "公司比个体户正规" | ❌ 100-1000 万营收区间，个体户省 7-15 万税 |
| "钱进对公更安全" | ❌ 个体户钱进个人卡，限制单笔 ≤ 20 万，月累计 ≤ 50 万 |

## 九、复盘与验证（执行后必走）

1. 营业执照下来后 → 国家企业信用信息公示系统查经营范围
2. 视频号小店开通后 → 查保证金（类目）+ 抽佣比例（平台）
3. 第一次卖课 → 查 7 天后结算金额（扣增值税 + 抽佣）
4. 季度报税 → 代账公司出报表后，核对"销项-进项-附加-个税"
5. 半年复盘 → 实际到手 vs 推演差异（应 < 1%）
