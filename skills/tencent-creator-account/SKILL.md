# 腾讯创作者账号规划

## 重要边界

平台准入、认证数量、保证金、类目、结算、工商和税务规则会变化。本 Skill 只提供决策框架，不给法律或税务定论；执行前必须查官方平台规则、当地市场监管和税务口径，必要时咨询持证专业人员。

## 收集需求

确认：

- 内容、课程、咨询、实物或数字商品类型；
- 目标账号和已有认证状态；
- 经营主体所在地与类型；
- 是否需要店铺、广告、直播、支付或团队权限；
- 预计交易规模与开票需求；
- 对责任、成本、融资和注销的要求。

不在公开记录中保存身份证号、统一社会信用代码、手机号、银行卡、店铺号或后台截图。

## 实时核验清单

按执行日期记录官方来源：

| 项目 | 需要核验 |
|---|---|
| 账号认证 | 主体要求、数量、年审和迁移规则 |
| 账号绑定 | 同主体、同名、展示和权限条件 |
| 店铺准入 | 类目、许可证、保证金和结算 |
| 商品发布 | 实物、课程、咨询和数字商品限制 |
| 平台费用 | 技术服务费、支付费和退款规则 |
| 工商 | 主体类型、经营范围和属地要求 |
| 税务 | 纳税身份、发票、申报和优惠适用条件 |

优先使用平台帮助中心、政府官网和正式合同，不依赖旧截图或转述文章。

## 方案比较

至少比较个人主体、个体工商户和公司三种路径：

| 维度 | 个人 | 个体工商户 | 公司 |
|---|---|---|---|
| 可用功能 | 以实时规则为准 | 以实时规则为准 | 以实时规则为准 |
| 责任边界 |  |  |  |
| 开票与结算 |  |  |  |
| 维护成本 |  |  |  |
| 税务处理 |  |  |  |
| 团队与融资 |  |  |  |
| 退出成本 |  |  |  |

不要写“永远更省”“唯一方案”“保证可开通”等绝对结论。

## 输出

```markdown
## 业务目标
## 当前账号与主体状态

## 方案对比

## 成本、责任和税务风险

```

## 执行后复核

核对认证主体、权限、保证金、费率、结算账户、发票、合同和可见范围。实际结果与方案不一致时更新规则记录，不把单次经验当成长期政策。
