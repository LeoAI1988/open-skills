# 公众号选题策划 Skill

## 一、用途

为内容创作者提供结构化的选题方法：选题池规划、方法论、标题公式、质量检查清单。适用于公众号、视频号、小红书等图文/视频平台。

## 二、选题池规划

按板块分配，保持内容多样性。可根据个人领域调整比例。

| 板块 | 比例 | 定位 |
|------|:--:|------|
| 核心专业领域 | 30% | 你最擅长、读者最认你的方向 |
| 痛点焦虑类 | 20% | 教育/职场/阶层/身份 |
| 消费决策类 | 20% | 性价比/源头/跨境/避坑 |
| 大众人性底层 | 30% | 情绪/欲望/认知颠覆 |

## 三、三大选题方法论

### 方法 1：情绪共鸣优先（咪蒙路线）

**核心问题：** 这个话题能让人转发吗？

- **锁定受众**：20-35 岁都市年轻人
- **聚焦主题**：职场 / 婚恋 / 原生家庭 / 阶层焦虑
- **选题标准**：能否激发强烈情绪（愤怒/委屈/共鸣/爽感）
- **内容角度**：替读者说出"不敢说的话" → "终于有人说了"的释放感

**标题公式：**
- "你的 X，正在毁掉你的 Y"
- "我年薪百万，但连一个朋友都没有"（极端反差+情绪词）
- "合群的人，到底有多可怕"（X 的人，到底有多 Y）
- "月薪 3 万的实习生教会我的 5 件事"（数字+悬念）

### 方法 2：焦虑+变现（知识付费路线）

**核心问题：** 这个风口能变现吗？

- **锁定受众**：想用新工具/新技能赚钱的普通人
- **选题标准**：FOMO 感 + 明确投入产出比
- **内容角度**：先放大焦虑，再给解决方案

**标题公式：**
- "普通人如何用 X+具体场景月入过万"
- "X 时代，90% 的 Y 会被淘汰"
- "我用 X 做了 Y，一单收 5000"（案例演示）

### 方法 3：成长扎心（青年成长路线）

**核心问题：** 这个痛点年轻人最共鸣吗？

- **锁定受众**：大学生 + 初入职场 1-5 年
- **选题标准**：永恒母题（努力≠结果/选择>努力/独立思考）
- **内容角度**：冷静地扎你一刀，温暖但克制

**标题公式：**
- "你只是看起来很努力"（悖论式）
- "爱抱怨的人，后来都怎么样了"
- "真正厉害的人，从不 XXX"（否定+新定义）

## 五、选题质量检查清单

每个候选选题逐条过：

- [ ] 目标受众明确？（不是"所有人"）
- [ ] 有情绪钩子？（愤怒/焦虑/好奇/爽感）
- [ ] 有信息差？（读者不知道的）
- [ ] 有反直觉角度？（不是"大家都这么说"）
- [ ] 标题有数字/极端词/悬念？
- [ ] 能一句话说清核心观点？
- [ ] 有独家素材支撑？（别人写不了）

## 六、执行流程

### 路径 A：自上而下（热点驱动）

1. **采集热点**：36kr / 华尔街见闻 / 微博热搜 / 知乎热榜
2. **按板块比例生成候选**：每个板块套标题公式出题
3. **质量检查**：逐条过清单
4. **输出选题池**：标题 + 角度 + 钩子逻辑 + 预估热度

### 路径 B：自下而上（素材驱动）

从已有的笔记/录音/日记中挖选题。

1. **全量采集素材**：用多组关键词搜索笔记系统，换主语/地点/事件/场景 5-10 组 query
2. **通读全文**：对每篇候选读完整内容（不要只看摘要），标记：
   - 📊 **数据爆点**：具体数字、对比
   - 💭 **情感高潮**：金句、哭笑冲突瞬间
   - ⚡ **天然冲突**：观念碰撞、代际差异
   - 🎯 **独家信息差**：别人没有的素材
3. **选题成型**：每个选题输出
   - 标题（套用公式库）
   - 角度（一句话视角）
   - 爆点（2-3 个，标注类型）
   - 适合平台（长文/口播/短视频）
   - 原文素材出处（方便回看）
4. **排序**：按"独家性 + 传播潜力"给优先推荐

### 选题额外检查（素材驱动时）

- [ ] 是否有独家数据/经历？
- [ ] 是否有足够细节支撑？
- [ ] 是否能触发"我也想这么做"的行动欲？
