# 内容选题策划

## 选题输入

先确认平台、受众、领域、发布频率、目标和可用素材。不要把所有人当作受众，也不要用虚构经历制造“独家感”。

## 建立选题池

按实际业务调整比例，可从四类开始：

| 类型 | 作用 |
|---|---|
| 专业解释 | 建立可信度，解决具体问题 |
| 决策避坑 | 帮助读者比较选择和成本 |
| 趋势变化 | 解释新事件对受众的影响 |
| 真实故事 | 用已授权素材呈现人物、冲突和转折 |

## 两条选题路径

### 热点驱动

1. 从官方来源、权威媒体和平台趋势页采集候选。
2. 核验事件发生时间和关键事实。
3. 找到“这件事为什么与目标受众有关”。
4. 生成标题、角度、证据需求和有效期。

### 素材驱动

1. 搜索用户授权的笔记、录音、访谈或案例。
2. 读取原文，不只依赖摘要。
3. 标记数据、冲突、转折、原话和行动结果。
4. 为每个候选保留私有来源指针，但公开成品不暴露姓名、账号、内部 ID 或关系信息。

## 标题方法

标题应明确主题、受众和信息增量，可使用：

- 反常识：为什么常见做法在特定条件下会失效；
- 对比：方案 A 与方案 B 的关键差异；
- 清单：完成一件事前必须核对的若干项；
- 案例：一次真实尝试带来的可复用结论；
- 时效：新规则或新产品改变了什么。

避免伪造收入、夸大百分比、恐吓式承诺和与正文无关的极端标题。

## 排序评分

每项按 1–5 分评估：

- 受众相关性；
- 信息增量；
- 素材充分度；
- 时效性；
- 传播钩子；
- 合规与隐私风险。

优先选择总分高且证据充分的选题。高传播但高风险的选题必须先降风险，不以流量替代真实性。

## 输出格式

| 优先级 | 标题 | 核心角度 | 受众 | 证据/素材 | 平台 | 风险 |
|---|---|---|---|---|---|---|

最后推荐 1–3 个，并说明为什么现在值得做。
