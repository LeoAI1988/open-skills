# 公众号文章写作

## 核心原则

1. 优先使用原始材料，不把自动摘要当作原文。
2. 保留用户的观点、事实和语言节奏，不虚构经历、数字或引语。
3. 用户要求先策划时先给标题与结构；用户明确要求直接成稿时直接写。
4. 用户确认定稿后，除非明确要求，不再改动正文。
5. 对公开稿执行隐私审查，移除姓名、联系方式、账号、内部 ID、私人关系和可识别细节。

## 工作流

### 1. 读取素材

确认主题、受众、平台、字数、立场和素材边界。长录音优先读取逐字稿；遇到说话人不明或关键事实冲突时标记不确定性。

### 2. 建立事实表

列出人物角色、时间、地点、事件、数字、引语和来源。公开稿用角色或职能称呼替代真实姓名，除非用户明确授权且确有必要。

### 3. 策划

输出 3–4 个标题候选、核心观点、结构和预计字数。标题不能超出证据，不用虚假冲突或结果承诺。

### 4. 写作

推荐结构：

- 具体场景或事实开头；
- 提出冲突或反常识；
- 用材料和案例推进；
- 给出机制解释或可执行结论；
- 用克制的总结收尾。

使用短句和自然段落，但不机械添加口头禅、排比和情绪词。每个引用和数字都能回到来源。

### 5. 自审

- 字数和交付格式正确；
- 无空洞开场、机械过渡和术语堆砌；
- 事实、日期、数字、引语已核验；
- 标题、正文和结尾立场一致；
- 没有个人或敏感信息；
- 没有未经授权的版权内容。

## 口播改写

从已确认文章中提取一条因果主线，按“钩子 → 冲突 → 解释 → 结论”重排。保留原意，不新增事实；使用短句和自然停顿，不添加舞台说明，除非用户要求分镜版。

## 交付

默认先交 Markdown 正文。用户明确确认文字定稿后，再处理配图、HTML、归档或发布。
