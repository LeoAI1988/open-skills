# 公众号文章写作

## 用途

从录音逐字稿、笔记、链接或主题完成公众号文章策划、写作、自审和改稿。根据用户要求选择情绪化、冷静分析、教程或口语叙事，不默认套用单一风格。

## 核心原则

### 1. 尊重用户指定流程

- 用户要求先策划：先给标题、结构和角度，确认后写正文。
- 用户明确要求直接成稿：直接完成，不重复确认。
- 用户已确认文字定稿：未经明确要求，不再改动正文。

### 2. 字数遵守指令

| 用户指令 | 执行 |
|---|---|
| “1000 字内” | 不超过 1000 字 |
| “2000–2500 字” | 保持在区间内 |
| 未指定 | 根据素材与平台选择合理长度 |

### 3. 优先使用原始材料

逐字稿、录音原文和用户提供的全文优先于自动摘要。拿不到原文时立即说明边界，不用摘要补写成“原话”。

### 4. 不虚构

人物、日期、数字、案例和引语必须能回到来源。公开稿中的用户本人或家人使用角色称呼，除非用户明确授权公开真实姓名。

## 写作流程

### 1. 读取需求与素材

确认主题、受众、平台、字数、立场、素材来源和结尾要求。一次性读完用户的全部指令再开始。

### 2. 建立事实表

记录人物角色、时间、地点、事件、数字、引语和出处。区分已确认事实、待核实信息和作者观点。

### 3. 策划

```markdown
## 策划方案

### 标题候选
1. [标题 A] — 角度：...
2. [标题 B] — 角度：...
3. [标题 C] — 角度：...

### 结构
- 开头：[具体场景或冲突]
- 中段：[3–5 个推进节点]
- 结尾：[金句、留白或行动]

### 目标字数
```

### 4. 写作

- 前 2–3 段提供具体画面、事实或冲突；
- 每个段落推进一个意思；
- 引用和数字保留来源；
- 文章节奏服务于内容，不机械套“首先、其次、最后”；
- 不把作者写成旁观的“用户”，直接以文章作者视角表达。

### 5. 自审

- 字数和交付格式正确；
- 标题没有超出证据；
- 开头不是空泛时代背景；
- 事实、日期、数字和引语可核验；
- 没有私人姓名、联系方式、账号、内部 ID 或家庭隐私；
- 公开人物、作者和作品名称引用准确；
- 没有未经授权的大段版权内容。

## 咪蒙式强情绪写作

咪蒙是公开的公众号作者和写作案例。用户明确要求“咪蒙风格”或强情绪传播稿时，可以研究其公开文章的机制，但不要伪造咪蒙的观点、经历或原句，也不要复制具体文章。

### 核心机制

情绪共鸣优先于抽象说教，让读者产生“终于有人说出来了”的释放感。

| 特征 | 做法 |
|---|---|
| 开头 | 使用具体场景，不用“随着时代的发展” |
| 短句 | 一句话一个意思，控制长句 |
| 情绪张力 | 使用明确立场和冲突，但不能夸大事实 |
| 替读者表达 | 说出常见但难以说出口的感受 |
| 反问 | 少量使用，推动冲突而非凑语气 |
| 排比 | 三项递进，避免机械堆砌 |
| 金句 | 形成 2–3 个可独立传播的句子 |
| 结尾 | 金句、留白或行动号召，与正文一致 |

### 禁用表达

- “随着时代的发展”；
- “值得注意的是”；
- “不可否认”；
- “在当今社会”；
- 无具体含义的“赋能、深耕、洞察、范式”；
- 为制造情绪而虚构的极端案例。

### 语音识别提示

“咪蒙”容易在逐字稿中被识别为“迷茫”。结合上下文确认：

- 咪蒙：公开作者及其强情绪公众号写作机制；
- 迷茫：普通情绪词，两者含义不同。

## 去 AI 味两遍法

### 第一遍：诊断

检查：

1. 空洞过渡句；
2. 并列概念堆砌；
3. 没有证据的宏大概括；
4. 套路化设问开头；
5. 机械三段论；
6. 过度引用；
7. AI 高频词；
8. 每段长度和句式完全一致。

### 第二遍：重写

用素材中的具体事实、原话节奏和自然长短句替换模板语言。重写后朗读一遍，检查是否像同一个真实作者写成。

## 短视频口播改写

触发示例：“改成短视频版”“视频号口播”“800 字以内”。

1. 从已确认文章提取 3–5 个核心观点。
2. 按“钩子 → 冲突 → 解释 → 结论”重排。
3. 每 10–15 秒设置一次信息推进。
4. 改为适合朗读的短句和自然停顿。
5. 保留原意，不新增未经来源支持的事实。

## 交付规则

- 默认先交 Markdown 正文；
- 用户说“删掉某段”时整段删除，不留影子句；
- 用户要求修改时直接按要求改，不强迫解释原因；
- 文字明确定稿后，再处理配图、HTML、归档或发布。

## 最终检查

- [ ] 是否遵守用户指定的流程和字数？
- [ ] 是否使用原始素材并区分事实与观点？
- [ ] 是否保留了有意义的公开人物、作者和作品引用？
- [ ] 是否没有出现用户本人、家人、联系方式、账号密码和私人经历？
- [ ] 是否没有编造案例、数字或引语？
- [ ] 定稿后是否保持正文不变？
