# 顶级思维决策系统 Skill

## 一、用途

为复杂的商业战略问题提供多维度分析框架。不替代用户决策，而是提供思考工具，帮助用户看清盲区。

**适用场景：**
- 战略选择（进哪个市场/做哪个产品）
- 方向探索（下一个增长点在哪）
- 业务诊断（为什么增长停滞）
- 重大决策（融资/并购/转型）

**不适用：** 简单的执行类任务（写代码/写文章/做表格）。

## 二、五大思维框架

### 框架 1：Active-Agent 执行引擎

**核心：** 把"思考"拆成"思考→执行→反馈→调整"的循环。

```
观察（Observe）→ 判断（Orient）→ 决策（Decide）→ 行动（Act）
     ↑                                                    ↓
     └──────────── 反馈（Feedback）←─────────────────────┘
```

**用法：** 面对复杂问题，不要一次性想清楚，而是：
1. 快速判断当前局面
2. 做最小可行决策
3. 执行后观察反馈
4. 根据反馈调整

### 框架 2：Best-Minds 顶级思维模拟

**核心：** 模拟顶级投资者的思考角度，审视当前决策。

| 思维者 | 视角 | 核心问题 |
|--------|------|---------|
| **霍华德·马克斯** | 位置感 | 我们在周期的哪个位置？该激进还是保守？ |
| **瑞·达里奥** | 分散化 | 风险是否集中？有没有未对冲的尾部风险？ |
| **彼得·林奇** | 认知完整性 | 我买的是什么？为什么买？赚的是什么钱？ |
| **查理·芒格** | 逆向思维 | 如果想失败，我会怎么做？反过来就是成功 |
| **贝佐斯** | 长期主义 | 10 年后这个决策还重要吗？什么不会变？ |

**用法：** 对每个重大决策，至少从 3 个 Best-Minds 视角审视。

### 框架 3：Expert-Team-Builder 多 Agent 辩论

**核心：** 模拟一个专家团队的讨论，让不同立场的声音都被听到。

**专家阵容（按问题类型选择）：**

| 问题类型 | 专家阵容 |
|---------|---------|
| 投资决策 | 多头分析师 + 空头分析师 + 风控官 + 宏观经济学家 |
| 产品决策 | 产品经理 + 工程师 + 设计师 + 销售总监 |
| 战略决策 | CEO + CFO + CTO + 竞争对手视角 |

**用法：**
1. 为每个专家写一段"他会怎么说"
2. 让专家之间产生分歧
3. 分歧点 = 决策的关键变量
4. 用户基于分歧做判断

### 框架 4：Insight 战略挑战

**核心：** 主动挑战用户的初始判断，避免确认偏误。

**3 个挑战问题：**
1. **"如果反过来呢？"** — 假设决策错误，最可能的原因是什么？
2. **"如果别人这么做呢？"** — 竞争对手/同行会怎么看这个决策？
3. **"如果 10 年后看呢？"** — 长期视角下，这个决策还成立吗？

**用法：** 用户给出初始判断后，必走 3 个挑战问题。

### 框架 5：商业判断

**核心：** 用第一性原理拆解商业本质。

**4 层拆解：**
1. **需求层：** 用户真正想要什么？（不是表面说的）
2. **供给层：** 为什么是你能做？（护城河）
3. **商业模型层：** 怎么赚钱？（收入模型）
4. **增长层：** 怎么做大？（可扩展性）

**用法：** 面对任何商业机会，走 4 层拆解，任何一层不成立 = 整个机会不成立。

## 三、执行流程

### Step 1：明确问题

把用户的问题重新表述为一个清晰的决策问题。

**模板：**
```
决策问题：[用户面临的选择]
当前倾向：[用户初步想法]
关键变量：[影响决策的 3-5 个因素]
时间约束：[必须何时决定]
```

### Step 2：框架选择

根据问题类型选择 2-3 个框架：

| 问题类型 | 推荐框架组合 |
|---------|-------------|
| 高不确定性 | Active-Agent + Insight 挑战 |
| 多方利益 | Expert-Team 辩论 |
| 长期影响 | BestMinds + 商业判断 |
| 商业机会 | 商业判断 + Insight 挑战 |

### Step 3：执行分析

按选择的框架逐一分析。

**输出格式：**
```markdown
## 框架 N 分析：[框架名]

### [框架的核心产出]

### 关键发现
- 发现 1
- 发现 2

### 风险提示
- 风险 1
```

### Step 4：综合结论

**不给单一答案，给决策矩阵：**

| 选项 | 优势 | 风险 | 适用条件 |
|------|------|------|---------|
| A | ... | ... | ... |
| B | ... | ... | ... |

**最终判断：** 基于综合分析，给出倾向性建议（不是命令）。

## 四、输出规范

1. **不给标准答案** — 只给思考框架和分析
2. **必走挑战问题** — 不能只说利好
3. **分歧点高亮** — 专家分歧的地方就是关键
4. **结论倾向性** — 给建议但不替用户决定
5. **不堆砌框架** — 选 2-3 个最贴的，不全部用上

## 五、常见陷阱

### 陷阱 1：只说利好

**症状：** 用户想做 X，所有分析都支持 X。

**修复：** 必走 Insight 挑战的 3 个问题。

### 陷阱 2：堆砌框架

**症状：** 5 个框架全用上，报告又长又泛。

**修复：** 根据问题类型选 2-3 个最贴的。

### 陷阱 3：替用户决定

**症状：** "你应该选 A"。

**修复：** 给决策矩阵，倾向性建议，但明确"最终由你决定"。

### 陷阱 4：专家意见一致

**症状：** 所有专家都说好。

**修复：** 专家必须有分歧。分歧点 = 关键变量。如果真的一致，说明问题太简单或没分析透。

### 陷阱 5：忽略长期视角

**症状：** 只看短期利弊。

**修复：** 必加贝佐斯"10 年后看"的问题。
