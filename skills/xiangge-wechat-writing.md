# 公众号文章写作 Skill

## 一、用途

从素材（录音逐字稿/笔记/链接/主题）直接输出公众号成品文章。覆盖：
- 情绪化咪蒙风格写作
- 策划先行流程
- 去 AI 味人声化
- 短视频文案改写

## 二、核心原则

### 原则 1：策划先行

**任何文章先出策划方案（标题候选+结构+角度），等用户确认再写。**

即使用户说"开始吧"，第一步仍是出 3-4 个标题方向让他选。

**原因：** v1 标题被全毙是常态。先策划后写作，避免白写。

### 原则 2：字数遵守指令

| 用户指令 | 字数 |
|---------|------|
| "1000 字内" | 死守 ≤ 1000 |
| "2000-2500" | 死守 2000-2500 |
| 没说 | 默认 3000 |

**铁律：** 死守用户指定字数。不擅自加长或缩短。

### 原则 3：先读全需求再动手

用户经常一次说多个需求。必须先读完所有指令再开始，不能看一半就急着出结果。

### 原则 4：拿不到原文立刻汇报

不要凭智能总结瞎写。recall 的智能总结会抹掉口语情绪/原话细节。

## 三、咪蒙风格要素

### 核心：情绪共鸣 > 逻辑论证

读者要的是"终于有人说了"的释放感，不是说教。

### 写作特征

| 特征 | 做法 |
|------|------|
| **开头** | 用具体场景，不用"随着 X 的到来" |
| **短句** | 一句话一个意思，不堆长句 |
| **情绪词** | 敢用极端词（最/永远/从不/所有） |
| **替读者说** | 说出读者不敢说的话 |
| **反问** | "难道不是吗？" |
| **排比** | 3 个一组，递进 |
| **金句** | 每篇 2-3 个可独立传播的句子 |
| **结尾** | 三件事/金句留白/行动号召 |

### 禁用词清单

- ❌ "随着时代的发展"
- ❌ "值得注意的是"
- ❌ "不可否认"
- ❌ "赋能/深耕/洞察/范式"
- ❌ "在当今社会"
- ❌ -ing 持续态（"正在改变"）

## 四、工作流

### Step 1：需求澄清

确认：
- 主题/素材来源
- 字数
- 风格（情绪化/冷静分析/教程）
- 目标受众
- 结尾格式（三件事/金句/行动号召）

### Step 2：策划方案

输出：
```markdown
## 策划方案

### 标题候选（3-4 个，套爆款公式）
1. [标题 A] — 角度：...
2. [标题 B] — 角度：...
3. [标题 C] — 角度：...
推荐：A

### 结构
- 开头：[钩子]
- 中段：[3-5 个分论点]
- 结尾：[金句/三件事]

### 字数
- 目标：XXX 字
```

**等用户确认再写。**

### Step 3：写作

按确认的方案写作。

**强钩子开头：**
- 前 2-3 段必须抓人
- 用具体场景，不用抽象概括
- 每 300 字换一个小节奏

### Step 4：自审

**交稿前必走自审清单：**
- [ ] 字数符合用户指令？
- [ ] 开头是强钩子？不是"随着 X"？
- [ ] 无 AI 高频词（赋能/深耕/洞察）？
- [ ] 有 2-3 个金句？
- [ ] 结尾符合用户要求？
- [ ] 引用的案例有出处？不是编的？

### Step 5：交付

- 交稿后不展开额外内容
- 用户说"改 X" → 立即改，不问 why
- 用户说"去掉某段" → 整段删干净，不保留

## 五、咪蒙不是迷茫

⚠️ 语音识别陷阱："咪蒙"容易被听成"迷茫"。

- 咪蒙 = 强烈情绪化的公众号风格
- 迷茫 = 完全不同的意思

**区分方法：** 听到"迷茫"立即警觉，确认是"咪蒙"再继续。

## 六、去 AI 味 2-pass

### Pass 1：诊断

按 8 大病症检查：
1. 过度过渡句（"值得注意的是"）
2. 并列堆砌（"A、B 和 C"）
3. 空洞概括（"在当今社会"）
4. 设问开头（"你有没有想过"）
5. 机械三段论（"首先/其次/最后"）
6. 过度引用
7. -ing 持续态
8. AI 高频词

### Pass 2：重写

每类病对应修改方法（详见 content-writing skill）。

**重写后再读一遍，确认"读起来像人写的"。**

## 七、短视频文案改写

**触发：** "改成短视频版""视频号文案""800 字以内"

### 流程

1. 提取原文的核心观点（3-5 个）
2. 按"钩子→冲突→解决"重构
3. 每 15 秒一个节奏点
4. 口语化（短句+口头禅）
5. 加字幕提示

**铁律：** 不重新创作，按原版文字和语料重新编排顺序和逻辑。

## 八、常见坑

| 坑 | 后果 | 规避 |
|----|------|------|
| 不策划直接写 | v1 全毙 | 先出策划方案 |
| 死守默认 3000 字 | 用户要 1000 字，写了 3000 | 死守用户指令 |
| 自己改用户定稿 | 用户怒 | 一字不改 |
| 引用编造案例 | 不可信 | 必须有出处 |
| 结尾强加三件事 | 用户说"去掉" | 立即删 |
| 标题用"青春不散场"等烂俗词 | 直接报废 | 列黑名单 |
| 听到"迷茫"不确认 | 写错方向 | 立即确认 |
| 写完后啰嗦解释 | 用户烦 | 交付即停 |

## 九、立场铁律（人物对比类）

写人物对比类文章（X vs Y）时：
- ❌ 不站队其中一方
- ❌ 不把一方写成"道义英雄"
- ✅ 客观呈现两种路线的差异
- ✅ 让读者自己判断

**铁律：** 文章里不出现"用户说""用户在录音里说"。用户就是作者，直接说内容就好。
